# SSD의 throughput saturation을 활용한 Selective Weight Loading 개선 방안

## 1. 연구 배경과 목표

- [ ] Selective Weight Loading이 필요한 배경을 설명한다.
- [ ] 중요도가 높은 행만 선택할 때 읽기 구간이 분산되는 문제를 설명한다.
- [ ] 중요도 보존과 SSD 읽기 비용 사이의 관계를 설명한다.
- [ ] 기존 Paper 방법과 비교해 개선하려는 점을 명시한다.
- [ ] 이번 중간 보고서에서 확인하려는 연구 질문을 정리한다.

## 2. 문제 정의와 제안 방법

- [ ] 행별 중요도, 선택 mask, 행 예산을 정의한다.
- [ ] 보존 중요도와 연속 구간의 읽기 비용을 정의한다.
- [ ] Top-R과 Paper의 선택 방식을 간략히 설명한다.
- [ ] Tiles의 타일 크기, 두 offset, 잔여 예산 처리 방식을 설명한다.
- [ ] 작은 예시 그림으로 세 방법의 선택 결과를 비교한다.

## 3. 실험 01 — Chunk 크기에 따른 SSD 읽기 비용

연구 질문: 읽기 크기에 따른 비용 변화를 어떤 모델로 설명할 수 있는가?

### 실험 설정

- [ ] 장치, 저장장치, thread 수, O_DIRECT 설정을 기록한다.
- [ ] 측정한 크기 범위와 반복 횟수를 기록한다.
- [ ] 측정값이 배치 처리량에서 환산한 chunk당 비용임을 설명한다.
- [ ] 모델 적합용 반복과 평가용 반복의 분리를 설명한다.

### 결과와 해석

- [ ] 그림: 크기별 읽기 비용과 처리량을 제시한다.
- [ ] 표: two-line, hinge, affine 모델의 평가 오차를 비교한다.
- [ ] 후속 최적화에서 two-line 모델을 사용하는 이유를 설명한다.
- [ ] 고정된 선택 행 수에서 짧은 연속 구간이 비용에 미치는 영향을 설명한다.
- [ ] 이 실험으로 확인한 사실과 모델의 가정을 구분한다.

## 4. 실험 02 — 비용 모델에서의 선택 알고리즘 비교

연구 질문: 같은 요청 예산에서 Tiles는 어떤 중요도–비용 관계를 만드는가?

### 실험 설정

- [ ] 중요도 trace를 수집한 모델, 입력, projection을 설명한다.
- [ ] 중요도 계산 방식과 비교한 행 예산을 기록한다.
- [ ] Global DP가 제공하는 기준과 적용되는 비용 모델을 설명한다.
- [ ] Paper, Tiles, Top-R의 설정을 기록한다.
- [ ] Paper는 요청 예산을 모두 채우지 않을 수 있음을 명시한다.

### 결과와 해석

- [ ] 그림: shape별 보존 중요도와 모델 추정 비용을 비교한다.
- [ ] Global DP와 각 방법의 차이를 정리한다.
- [ ] 타일 크기에 따라 결과가 어떻게 달라지는지 설명한다.
- [ ] 그림: 선택된 연속 구간의 길이 분포를 비교한다.
- [ ] Tiles가 유리한 조건과 불리한 조건을 정리한다.

## 5. 실험 03 — 실제 선택 시간과 SSD 읽기 시간 비교

연구 질문: 모델에서 관찰한 이점이 실제 실행 시간에서도 나타나는가?

### 실험 설정

- [ ] 측정에 사용한 trace 수와 행 예산을 기록한다.
- [ ] Paper 튜닝 기준과 최종 설정을 기록한다.
- [ ] Tiles의 기준 크기와 비교한 타일 크기를 기록한다.
- [ ] 실제 사용한 장치, reader 설정, warmup, 반복 횟수를 기록한다.
- [ ] 방법별 실행 순서와 전체 행 선택 시의 처리를 설명한다.
- [ ] selection_ms, io_ms, wall_ms의 측정 범위를 정의한다.

### 결과와 해석

- [ ] 그림: 보존 중요도와 실제 읽기 시간의 관계를 비교한다.
- [ ] 표: 선택 시간, 읽기 시간, 전체 시간을 구분해서 비교한다.
- [ ] 같은 trace와 요청 예산에서 Paper 대비 차이를 정리한다.
- [ ] 선택 계산 비용을 포함해도 개선이 유지되는지 설명한다.
- [ ] 연속 구간의 길이와 실제 읽기 결과를 함께 해석한다.
- [ ] 실험 02의 모델 결과와 일치하거나 달라지는 부분을 설명한다.
