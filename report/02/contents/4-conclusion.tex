\chapter{결론}\label{chap:conclusion}

본 보고서는 타일을 단위로 행을 선택하는 Tiles를 VLM의 모든 projection에 적용하고, Jetson Orin Nano에서 모델의 정확도와 프레임당 시간을 측정하였다. 이를 위해 행의 저장 순서를 정하는 hot--cold 재배열과 projection별 행 예산을 정하는 TEAL의 탐색을 정리하고, Neuron Chunking과 같은 방식으로 적용하였다.

Tiles는 Neuron Chunking의 greedy 방법과 같은 수준의 정확도와 읽기 시간을 더 짧은 선택 시간으로 얻었다. 가중치의 30--70\%를 읽는 세 조건에서 두 방법의 정확도 차이는 최대 0.5\%p였고, 프레임당 읽기 시간의 차이는 4 ms 이내였다. 선택 시간은 Tiles가 약 7 ms, greedy 방법이 99--106 ms였다. 그 결과 로딩 시간은 Tiles가 greedy 방법의 56--66\%였고, 세 조건 모두에서 모든 가중치를 읽는 것보다 짧았다.

선행 연구 \cite{seol2026}는 가중치 행렬 하나에서 두 방법의 읽기 시간이 비슷하고 선택 시간에서 차이가 난다는 것을 보였다. 같은 관계가 VLM 전체의 프레임당 시간에서도 나타났으며, 두 방법의 정확도는 구별되지 않았다.

본 보고서의 한계는 다음과 같다.

\begin{itemize}
\item \textbf{정확도의 해상도}: 질문 391개에서 두 방법의 짝지은 차이는 95\% 신뢰구간의 폭이 3.3--5.1\%p이다. 이보다 작은 정확도 차이는 구별하지 못한다.
\item \textbf{추론과 읽기의 분리}: 정확도는 모든 가중치를 메모리에 둔 채 선택되지 않은 입력 채널을 0으로 두어 측정하였고, 읽기 시간은 영상 하나에서 따로 측정하였다. 선택한 행만 플래시에서 읽어 추론하는 전체 과정은 실행하지 않았다.
\item \textbf{모델과 자료}: 모델 하나와 평가 자료 하나, 세 가지 요청 비율에서 측정하였다. Neuron Chunking이 평가한 더 큰 모델에서의 확인이 필요하다.
\item \textbf{준비 과정의 효과}: Hot--cold 재배열과 projection별 예산을 하나씩만 적용한 실행이 없어, 두 과정 각각의 효과를 나누어 보지 못하였다.
\end{itemize}
