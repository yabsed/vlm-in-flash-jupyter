\EnglishAbstractHeader

When a large language model runs on a portable device, the weights that do not fit in DRAM stay on flash, and only the rows that matter for the current input are read. The throughput of an SSD rises with the request size and then saturates, so the time to read a given number of rows depends on how contiguous the selected rows are. Neuron Chunking by Yang et al. takes this into account and poses row selection as maximizing the retained importance per unit of estimated read time.

This thesis shows that, because that problem only bounds the number of rows from above, a single contiguous chunk is always optimal, and it restates the problem as selecting exactly $R$ rows. It then introduces a two-line latency model that approximates throughput saturation with two line segments. Under this model the read cost splits into a cost proportional to the number of rows and an extra cost of short chunks. Based on this, the thesis presents Global DP, which finds the optimal mask with dynamic programming and Dinkelbach's method, and Tiles, which selects rows in tiles of a fixed length. It also shows that when every chunk is at least as long as the breakpoint, the importance retained relative to Top-$R$ is a lower bound on the ratio achieved relative to the optimum.

On the read costs measured on the NVMe SSD of a laptop, the two-line model had a test MAPE of 3.4\%. With importance collected from a language model, at 50\% of the rows of an $896\times896$ weight matrix, Tiles reached 95.9\% of the optimal ratio and the greedy method of Neuron Chunking 96.8\%. In real measurements the two methods took about the same time to read from the SSD, but Tiles took about one hundredth of the time to select the rows. As a result the total time of selection and reading was about one third for Tiles, while its retained importance was 3.6 percentage points lower.
